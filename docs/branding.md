# Identité visuelle

← [Documentation](README.md)

Le logo associe une maison et des éléments de chauffage. Il représente le projet indépendant Heatzy Local ; il ne prétend pas être le logo officiel Heatzy ou Home Assistant.

- Master transparent : [heatzy-local-logo.png](assets/heatzy-local-logo.png).
- Icône standard 256 px : `custom_components/heatzy_local/brand/icon.png`.
- Icône haute définition 512 px : `custom_components/heatzy_local/brand/icon@2x.png`.

Le master original a été généré pour ce projet, puis décliné en tailles d'icône sans modifier son dessin. Les fichiers sont distribués avec le projet sous sa licence MIT.

Le dossier local `brand/` est pris en charge depuis Home Assistant 2026.3 ; le minimum déclaré ici reste 2026.10.1. Aucun accès à un CDN d'images n'est nécessaire pour ces icônes locales.

Sources : [Home Assistant](https://developers.home-assistant.io/blog/2026/02/24/brands-proxy-api/) et [exigences HACS pour une intégration](https://www.hacs.xyz/docs/publish/integration/).
